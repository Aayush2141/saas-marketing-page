# FlowOS - Where Focus Meets Flow

A modern, dark-themed landing page for a productivity application built with HTML and CSS featuring glassmorphism design.

## About

FlowOS is a productivity platform designed to help students, creators, and professionals manage their tasks, automate workflows, and track their focus in one unified system.

## Features

- **Clean Dark Theme**: Easy on the eyes with a modern dark color scheme
- **Glassmorphism Design**: Frosted glass effect for a contemporary look
- **Fully Responsive**: Works on desktop, tablet, and mobile devices
- **Simple & Professional**: Built with beginner-friendly HTML and CSS

## Project Structure

```
flowos/
├── index.html          # Main HTML file
├── style.css           # Stylesheet with glassmorphism effects
└── README.md           # Project documentation
```

## Technologies Used

- HTML5
- CSS3
  - Flexbox
  - CSS Grid
  - Backdrop Filter (for glassmorphism)
  - Media Queries (for responsive design)

## Sections

1. **Header**: Sticky navigation with logo and CTA button
2. **Hero**: Main landing section with tagline and call-to-action
3. **Features**: Three key features of FlowOS
4. **How It Works**: Four-step process explanation
5. **Pricing**: Three pricing tiers (Starter, Pro, Ultimate)
6. **CTA**: Call-to-action section encouraging sign-ups
7. **About**: Information about FlowOS
8. **Footer**: Links and copyright information

## Design Elements

- **Color Scheme**: Dark slate background (#0f172a) with indigo accents
- **Typography**: Arial font family for simplicity
- **Effects**: Glassmorphism with backdrop blur
- **Layout**: CSS Grid for feature cards and pricing cards

## Setup

1. Download the project files
2. Open `index.html` in your web browser
3. No additional setup or dependencies required

## Browser Compatibility

Works best in modern browsers that support:
- CSS Grid
- Flexbox
- backdrop-filter property

Tested on:
- Chrome
- Firefox
- Safari
- Edge

## Responsive Breakpoints

- Desktop: Default styles
- Tablet/Mobile: 768px and below
